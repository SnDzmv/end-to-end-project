# Неделя 2

## Цель
Реализовать Extract данных из World Bank API для варианта 13 (ЮАР, безработица %).

---

## Этапы реализации
1. Подготовка окружения:
   - Установить Python-библиотеки: `requests`, `pyyaml`.
2. Подключение к API:
   - Использовать URL и параметры из `configs/variant_13.yml`.
3. Отправка запроса и получение данных:
   - Сделать GET-запрос с таймаутом.
   - Обработать возможные HTTP ошибки.
4. Сохранение сырых данных:
   - Сохранить JSON в папку `data/raw/` с timestamp в имени файла.
5. Тестирование:
   - Проверить, что JSON корректно сохраняется.
   - Убедиться, что структура проекта соответствует требованиям.

---


## Выходные артефакты
- Скрипт: `src/extract.py`
- Конфигурация: `configs/variant_13.yml`
- Raw JSON: `data/raw/raw_YYYYMMDD_HHMMSS.json`
