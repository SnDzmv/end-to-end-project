# Неделя 4

## Цель
Построить витрину данных (mart) на основе normalized слоя для анализа уровня безработицы (%) по варианту 13 (ЮАР).

---

## Этапы реализации

1. Загрузка данных:
   - Загрузить normalized CSV из `data/normalized/variant_13`
   - Загрузить справочник стран из `reference/countries.csv`

2. Проверка справочника:
   - Проверить количество строк
   - Проверить уникальность ключа `countryiso3code`
   - Убедиться в отсутствии дубликатов

3. Объединение данных (join):
   - Выполнить merge по `countryiso3code`
   - Использовать `validate="many_to_one"`
   - Проверить количество строк до и после объединения

4. Работа с датой:
   - Преобразовать поле `date` в формат datetime
   - Выделить год (`year`) как основную временную гранулярность
   - Отсортировать данные по времени

5. Расчет метрик (KPI):
   - Рассчитать значение предыдущего года (`value_prev`)
   - Рассчитать абсолютное изменение (`value_diff`)
   - Рассчитать темп роста (`growth_rate`)
   - Определить тренд (`trend`)
   - Рассчитать скользящее среднее (`rolling_avg_3`)

6. Формирование витрины:
   - Выбрать необходимые колонки
   - Добавить данные из справочника (регион, уровень дохода)
   - Подготовить таблицу для анализа временного ряда

7. Сохранение результата:
   - Сохранить итоговый CSV в `data/mart/variant_13`
   - Проверить корректность файла

8. Тестирование:
   - Убедиться, что строки не размножились после join
   - Проверить корректность расчетов KPI
   - Проверить отсутствие ошибок в данных

---

## Выходные артефакты

- Скрипт: `src/mart.py`
- Витрина данных: `data/mart/variant_13/mart_yearly.csv`
- Справочник: `reference/countries.csv`
