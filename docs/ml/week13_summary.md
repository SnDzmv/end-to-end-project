# Week 13 — Основы ML для аналитика

## Постановка задачи

Целью работы было построение простой модели прогнозирования значения показателя страны на основе исторических данных.

Целевая переменная (target):

- value

Признак (feature):

- year

Модель используется как демонстрация базового ML-подхода и сравнивается с простым бейзлайном.

---

## Train/Test Split

Данные являются временным рядом, поэтому использовалось разделение по времени:

- Train — прошлые годы
- Test — будущие годы

Это позволяет избежать утечки информации из будущего.

---

## Защита от Data Leakage

Были соблюдены следующие правила:

- целевая переменная не включалась в признаки;
- модель обучалась только на тренировочной выборке;
- тестовые данные не использовались при обучении;
- разделение выполнено по времени.

---

## Бейзлайн

В качестве бейзлайна использовался DummyRegressor со стратегией среднего значения.

Бейзлайн показывает качество модели «ничего не делать».

---

## Модель

Использована модель:

- LinearRegression

Модель обучалась на тренировочной выборке и затем применялась к тестовой.

---

## Метрика качества

Использовалась метрика MAE (Mean Absolute Error).

MAE показывает среднюю абсолютную ошибку прогноза.

Чем меньше значение MAE, тем лучше модель.

## Вывод

Модель LinearRegression показала работоспособность на имеющемся наборе данных.

Из-за небольшого количества наблюдений и использования только одного признака качество модели ограничено.

Работа позволила продемонстрировать:

- корректный train/test split;
- отсутствие data leakage;
- использование бейзлайна;
- оценку качества модели по метрике MAE.

Для повышения качества прогноза в дальнейшем можно использовать дополнительные признаки и более сложные модели.
